# Repository instructions

- This is an independent clean-room learning repository for one bounded metrics-monitoring-and-alerting invariant.
- Keep sample acceptance, durable ingestion, query visibility, rule evaluation, alert transition, notification provider acceptance,
  recipient device delivery, human acknowledgement, remediation, and recovery as separate facts.
- Never add real credentials, tenant names, hostnames, labels, metric values, incident history, on-call contacts, internal system
  metadata, copied third-party prose, diagrams, images, data, or code.
- Preserve unrelated work. Stage exact paths, keep commits single-purpose, and do not add co-author trailers unless requested.
- Infrastructure-dependent conclusions require the matching real service or true process boundary in public CI; mocks cannot prove
  durable restart, transactional outbox behavior, concurrent evaluation, or notification recovery.
- A benchmark is a bounded synthetic observation for its exact fixture and runtime, never a production-capacity or SLA claim.
