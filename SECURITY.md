# Security policy

This repository accepts only synthetic metrics, labels, rules, incidents, notification targets, and failure traces. Do not report
or attach real credentials, tenant identities, hostnames, metric values, production topology, alert history, on-call contacts,
provider endpoints, or internal observability metadata.

For a suspected repository vulnerability, open a GitHub security advisory when a public remote exists. Public issues are suitable
only for non-sensitive correctness bugs. This laboratory is not a deployed monitoring, alerting, or emergency-response system.
